# 🏝️ Mekkers Building Paradise — Paradise Bot

Final Discord bot for the Rust building community.

## Railway
Set `DISCORD_TOKEN`, `CLIENT_ID`, and `GUILD_ID` as Railway variables.
Build: `npm run build`
Start: `npm start`

Commands are registered automatically on startup.

## Main features
- Verification + welcome
- Server guide/info
- Staff announcements + changelogs
- Build submissions, staff approval and ratings
- Build orders + claiming/completion
- Builder points, profiles and leaderboard
- Tutorial/guide submissions
- Builder portfolio submissions
- Staff moderation tools
- Tropical Paradise branding

Never commit a real Discord token to GitHub.
